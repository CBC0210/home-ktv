# 完整功能複查 — 2026-05-16 (b)

第二輪端到端複查。全程透過 Cloudflare (`https://ktv.bc-verse.com`) + 真實 WS 客戶端測試。

## 🔴 本輪發現並修正的重大 bug

**入房密碼欄位不一致 — 密碼保護房間完全無法加入**
- 前端 `joinRoom` 送 `{password}`；後端 `GuestJoin` schema 只認 `room_password`。
- home 房過去 `password_hash=NULL`（與 README/CLAUDE.md §0.2 文件的「密碼 home」不符），所以密碼分支從未執行 → bug 被掩蓋。
- 依規格把 home 設回 join 密碼 `home` + `is_default=True` 後，bug 浮現：前端送的 `password` 後端讀不到 → 任何人 403 進不來。
- **修正**：`GuestJoin` 同時接受 `password` 與 `room_password`（`effective_password`）。實測：錯密碼 403、`home` 正確 200（兩種欄位都通）。
