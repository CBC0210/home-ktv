## 5. 推薦演算法

3 層：① 同演唱者 ready 歌 → ② 同曲風 → ③ 全站熱門，皆排除已播。
排行榜「個人/我的最愛」已移除（與資料庫 tab 重複）。

## 6. 已知限制 / 待辦

- **既有 12 首 genre** 背景回填中（`/tmp/genre_backfill.log`）；完成後同曲風推薦才對舊歌生效。
- **MiniMax 額度**：Plus 方案有 5 小時用量上限；超量時 LLM 自動退回 regex 清理。
- **背景 prefetch** 對冷門歌較慢（多來源 + YouTube 偶爾 429），不阻塞播放。
- 字幕時間軸本質依賴來源 LRC 準度；延遲調整是人工補救手段。
- `playback.setPitch` / `setSpeed` 指令前端有型別但 Player 未實作（移調/變速，CLAUDE.md 標二期）。
